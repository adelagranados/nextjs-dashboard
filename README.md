# Proyecto: Next.js App Router Course - Starter

Este proyecto fue desarrollado siguiendo el curso de Next.js App Router. Contiene el código inicial para una aplicación de dashboard.

## Descripción

Este repositorio es la plantilla inicial utilizada en el curso de Next.js App Router. Ayuda a comprender cómo estructurar y desarrollar una aplicación con Next.js utilizando el nuevo sistema de enrutamiento.

## Tecnologías utilizadas

- Next.js
- React
- JavaScript/TypeScript (según corresponda)
- Tailwind CSS (si aplica)

## Instalación

1. Clonar el repositorio:
   ```bash
   git clone [URL del repositorio]
   ```
2. Navegar al directorio del proyecto:
   ```bash
   cd nextjs-app-router-course
   ```
3. Instalar dependencias:
   ```bash
   npm install  # o yarn install
   ```
4. Ejecutar el proyecto:
   ```bash
   npm run dev  # o yarn dev
   ```

## Uso

Abre tu navegador y accede a `http://localhost:3000` para ver la aplicación en funcionamiento.
